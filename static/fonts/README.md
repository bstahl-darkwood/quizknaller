# Schriften

Selbst gehostet statt über Google Fonts (schneller auf langsamen Netzen, keine Daten an Dritte).
Alle drei stehen unter der SIL Open Font License 1.1 (https://openfontlicense.org), Selbsthosten
und Zuschneiden ist erlaubt.

| Datei | Schrift | Zuschnitt |
|---|---|---|
| montserrat-*.woff2 | Montserrat (Julieta Ulanovsky u. a.) | variabel, Stärke 700–900 |
| inter-*.woff2 | Inter (Rasmus Andersson) | variabel, Stärke 400–700 |
| caveat-*.woff2 | Caveat (Impallari Type) | 700, ohne Zeichenvarianten |

Zeichen: Basis-Latein, Latin-1 (ä ö ü ß é …), typografische Anführungszeichen, Gedankenstrich, €, Pfeile.
Caveat nur Buchstaben, Ziffern, Umlaute und gängige Satzzeichen.
Erzeugt mit fontTools (varLib.instancer + subset). Der Hash im Dateinamen ändert sich mit dem Inhalt,
daher dürfen die Dateien ein Jahr gecacht werden.
